# React Grocery List App

A sleek, lightweight, and mobile-friendly grocery list web application built with **React** and **Vite**. Features seamless state persistence, a modular component architecture, and responsive design optimized for both mobile phones and desktop computers.

---

## ✨ Features

- **Dynamic Item Management:** Add new items, toggle items as completed (with smooth strikethrough styling), and delete individual items.
- **Data Persistence:** Automatically saves your list using the browser's `localStorage` so your items stay intact even after refreshing or closing the browser.
- **Clear List:** Quickly wipe the entire list with a single action when you're done shopping.
- **Mobile-First & Responsive:** Designed to look and feel like a native mobile app on phones, while smoothly expanding into a centered card layout on desktops using CSS media queries.
- **PWA-Ready:** Configured with a Web App Manifest and Apple Touch Icons so users can easily **"Add to Home Screen"** on iOS and Android devices.

---

## 🛠️ Tech Stack

- **Framework:** React (Vite)
- **Styling:** Vanilla CSS (CSS3, Flexbox, Media Queries)
- **State Management:** React Hooks (`useState`, `useEffect`)
- **Persistence:** Browser LocalStorage API
